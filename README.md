# Project GATE

Project GATE представляет собой псевдо-3D шутер от первого лица.

GATE расшифровывается как Genesis Anomaly Testing Environment(Среда тестирования аномалий Genesis). Действие игры происходит в секретной лаборатории, где эксперимент с аномальным разломом вышел из-под контроля. Игрок выступает в роли выжившего сотрудника комплекса. Ему нужно исследовать зараженные секторы, сражаться с противниками, собирать аптечки и патроны, а затем активировать выходной терминал.

В кампании необходимо пройти пять процедурно сгенерированных секторов. С каждым сектором карты становятся больше, а количество врагов увеличивается. Также в игре есть бесконечный режим, в котором генерация секторов продолжается без ограничения, а игрок набирает очки.

В игре реализованы два вида оружия и два типа врагов. Противники умеют замечать игрока, преследовать его, искать последнюю известную позицию, открывать двери и атаковать. В интерфейсе отображаются здоровье, патроны, текущее оружие, счет, задача сектора и мини-карта.

## Используемые алгоритмы

- **Ray Casting**. Выпускает лучи из позиции игрока и находит пересечения со стенами, дверями и терминалом. Результат используется для построения псевдо-3D изображения уровня.

- **BSP Dungeon Generation**. Рекурсивно делит карту на области, размещает внутри них комнаты и соединяет комнаты коридорами. Благодаря этому каждый сектор имеет новую структуру.

- **Алгоритм Дейкстры**. Прокладывает коридоры между комнатами. Разным типам клеток назначается разная стоимость, поэтому коридоры стараются не разрушать стены комнат и могут использовать уже существующие пути.

- **A\***. Ищет маршрут врага до игрока или до его последней известной позиции. Манхэттенское расстояние используется как эвристика для направления поиска к цели.

- **BFS / Flood Fill**. Проверяет сгенерированную карту перед началом игры. Алгоритм убеждается, что игрок может добраться до терминала, врагов, дверей и ресурсов.

- **PRD**. Управляет появлением сильных врагов. После каждой неудачной попытки вероятность их появления увеличивается, а после успеха возвращается к начальному значению.

- **FSM**. Конечные автоматы управляют состояниями врагов, дверей и игровых сцен. Например, враг может ожидать, преследовать, искать игрока или атаковать, а дверь может быть закрыта, открываться, оставаться открытой и закрываться.

- **Line of Sight и Random Walk**. Проверка прямой видимости не дает врагам замечать игрока через стены. Пока игрок не обнаружен, враги выбирают случайные соседние клетки и перемещаются по комнате.

## Управление

- `W`, `A`, `S`, `D`: движение
- Стрелки влево и вправо: поворот камеры
- `Space`: выстрел
- `R`: перезарядка
- `Q`: смена оружия
- `E`: открыть дверь, активировать терминал или выбрать пункт меню
- Стрелки вверх и вниз: навигация по меню
- `Esc`: возврат в главное меню

## Установка и запуск


```bash
python -m pip install -r requirements.txt
python main.py
```

## Тесты

```bash
python -m pytest
```

Тесты проверяют поиск пути, генерацию и валидацию уровней, модели, коллизии, боевую систему, двери, PRD и переходы между секторами.
